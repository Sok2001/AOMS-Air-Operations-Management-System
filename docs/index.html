ABOUT THE PROJECT

Built as a desktop-first software project.

AOMS is developed with Python and a local SQLite database. Its interface is built with CustomTkinter, with a modular structure for operational data and supporting tools.

Technology stack

A lightweight desktop architecture designed for local use.
